# CLI Tools Agent Template: Dockerized Build Utility

## Category: CLI Tools

---

## 1. Overview

A pattern for creating lightweight, containerized CLI tools that:
- Encapsulate complex dependencies (runtimes, compilers, processors)
- Provide a simple host-side interface
- Work cross-platform (Linux, macOS, Windows via WSL2/Git Bash)

### 2.2 Layer Responsibilities

| Layer | File(s) | Responsibility |
|-------|---------|----------------|
| **Installation** | `install.sh` | Builds Docker image, deploys wrapper to PATH |
| **Host Wrapper** | `spec-build.sh` | User interface, Docker availability check, argument parsing |
| **Container Env** | `Dockerfile` | Dependency encapsulation (Java, Graphviz, PlantUML) |
| **Core Logic** | `internal-build.sh` | File discovery, transformation, output generation |

## 3. Execution Flow

### 3.1 Installation Phase

```
Developer → install.sh
              ├── docker build -t proveo/spec:latest .
              ├── Copy spec-build.sh → /usr/local/bin/spec
              ├── chmod +x
              └── "All set (run 'spec --help')"
```

### 3.2 Build Phase

```
Developer → spec [target_dir] [options]
              │
              ├── Resolve target_dir (default: pwd)
              ├── Check Docker available (command + daemon)
              │     └── Error if missing
              │
              └── docker run --rm -v <target>:/data proveo/spec:latest
                    │
                    └── Container starts
                          ├── Mount folder as /data
                          ├── ENTRYPOINT: entrypoint.sh
                          ├── Find *.puml (excluding .git, dist, build)
                          ├── Loop: java -jar plantuml.jar -tsvg <file>
                          └── Write <file>.svg next to source
```

## 4. CLI Design Pattern

### 4.1 Standard Options

| Flag | Short | Purpose | Scope |
|------|-------|---------|-------|
| `--verbose` | `-v` | Detailed output | Passed to container |
| `--dry-run` | `-d` | Preview command | Host-only |
| `--debug` | — | Shell tracing (`set -x`) | Both |
| `--help` | `-h` | Usage info | Host-only |

### 4.2 Argument Parsing Template

```bash
main() {
  local target_dir="$(pwd)"
  local verbose=0
  local dry_run=0
  local debug_mode=0

  while [[ $# -gt 0 ]]; do
    case "${1}" in
      -v|--verbose) verbose=1; shift ;;
      -d|--dry-run) dry_run=1; shift ;;
      --debug) debug_mode=1; shift ;;
      -h|--help) usage; exit 0 ;;
      -*) echo "Unknown option: ${1}" >&2; usage; exit 1 ;;
      *)
        # Positional: validate and resolve
        if [[ -d "${1}" ]]; then
          target_dir="$(cd "${1}" && pwd)"
        else
          echo "Error: Directory '${1}' not found." >&2
          exit 1
        fi
        shift
        ;;
    esac
  done

  if [[ "${debug_mode}" -eq 1 ]]; then set -x; fi
  # ... rest of logic
}
```

### 4.3 Usage Function Template

```bash
usage() {
  cat <<EOF
Usage: $(basename "${0}") [target_dir] [options]

Arguments:
  target_dir       Directory to scan (default: current directory)

Options:
  -v, --verbose    Enable verbose mode
  -d, --dry-run    Print the docker command without executing
  --debug          Enable shell debugging (set -x)
  -h, --help       Show this help message
EOF
}
```

## 5. Bash Best Practices

### 5.1 Strict Mode (All Scripts)

```bash
#!/usr/bin/env bash
set -o errexit   # Exit on error
set -o nounset   # Error on undefined variables
set -o pipefail  # Propagate pipe failures
```

### 5.2 Script Guard

```bash
if [[ "${BASH_SOURCE[0]}" == "${0}" ]]; then
  main "$@"
fi
```

### 5.3 Readonly Constants

```bash
readonly IMAGE_NAME="proveo/spec:latest"
readonly PLANTUML_JAR="/opt/plantuml.jar"
readonly EXCLUDE_DIRS=("dist" "build" ".git" "node_modules")
```

### 5.4 Dependency Check Pattern

```bash
check_docker() {
  if ! command -v docker &> /dev/null; then
    echo "Error: docker command not found." >&2
    return 1
  fi
  if ! docker info &> /dev/null; then
    echo "Error: docker daemon is not running." >&2
    return 1
  fi
  return 0
}
```

## 6. Dockerfile Pattern

```dockerfile
# 1. Minimal base image
FROM eclipse-temurin:17-jre-alpine

# 2. Metadata
LABEL maintainer="Organization"
LABEL description="Tool Description"

# 3. System dependencies (single layer)
RUN apk add --no-cache bash graphviz ttf-droid ttf-dejavu

# 4. Application dependencies (versioned via ARG)
ARG PLANTUML_VERSION=1.2024.3
RUN wget "https://...plantuml-${PLANTUML_VERSION}.jar" -O /opt/plantuml.jar

# 5. Entrypoint script (with CRLF sanitization for Windows compatibility)
COPY internal-build.sh /usr/local/bin/entrypoint.sh
RUN sed -i 's/\r$//' /usr/local/bin/entrypoint.sh
RUN chmod +x /usr/local/bin/entrypoint.sh

# 6. Working directory and entrypoint
WORKDIR /data
ENTRYPOINT ["/usr/local/bin/entrypoint.sh"]
```

## 7. Installation Script Pattern

```bash
main() {
  # 1. Build Docker image
  echo "Building Docker image '${IMAGE_NAME}'..."
  if [[ "${verbose}" -eq 1 ]]; then
    docker build -t "${IMAGE_NAME}" .
  else
    docker build -t "${IMAGE_NAME}" . > /dev/null
  fi

  # 2. Sanitize line endings (Windows compatibility)
  local temp_file=$(mktemp)
  tr -d '\r' < "${SOURCE_FILE}" > "${temp_file}"

  # 3. Install with privilege escalation if needed
  if [[ -w "${DEST_DIR}" ]]; then
    cp "${temp_file}" "${DEST_FILE}"
    chmod +x "${DEST_FILE}"
  else
    echo "Need elevated permissions to write to ${DEST_DIR}."
    sudo cp "${temp_file}" "${DEST_FILE}"
    sudo chmod +x "${DEST_FILE}"
  fi

  rm "${temp_file}"
  echo "All set. Run 'spec --help' to get started."
}
```

## 8. File Discovery Pattern (Container)

```bash
readonly EXCLUDE_DIRS=("dist" "build" ".git" "node_modules")

main() {
  # Build dynamic find command
  local find_cmd=(find . -type d \( -name "${EXCLUDE_DIRS[0]}")
  for ((i=1; i<${#EXCLUDE_DIRS[@]}; i++)); do
    find_cmd+=(-o -name "${EXCLUDE_DIRS[i]}")
  done
  find_cmd+=( \) -prune -o -type f -name "*.puml" -print )

  # Collect files
  local files=()
  while IFS= read -r file; do
    files+=("${file}")
  done < <("${find_cmd[@]}")

  # Process
  for file in "${files[@]}"; do
    process_file "${file}"
  done
}
```

## 10. Design Principles Summary

| Principle | Implementation |
|-----------|----------------|
| **Dependency Isolation** | All heavy deps in container |
| **Cross-Platform** | CRLF sanitization, Alpine base |
| **Zero Host Pollution** | Only single wrapper script installed |
| **Idempotent** | Re-running install updates cleanly |
| **Fail-Fast** | Validate prerequisites before execution |
| **In-Place Output** | Generated files alongside sources |
| **Sensible Defaults** | Works with no arguments |
| **Self-Documenting** | PlantUML diagrams in `_spec/` |
